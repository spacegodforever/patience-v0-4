# SYNTHETIC EXAMPLE DATA (not real market data)

Everything in this folder is invented for testing and demonstration. Company names (SYN-FAB, SYN-EQP,
SYN-MEM) are fictional. Values are generated by simple formulas (a linear drift plus a sine wave) with two
deliberately planted features so the statistics have something to find: one anomalous SYN-MEM value and
three missing weeks for SYN-EQP. Do not read any trend here as a statement about real companies.

- `sample_market_weekly_SYNTHETIC.csv`: 40 weekly "close" values per fictional company (category public_market).
- `sample_logistics_leadtime_SYNTHETIC.csv`: 40 weekly lead times in days (category internal_docs).
- `sample_filing_SYNTHETIC.txt`: example filing-style text (category public_filings).
- `sample_logistics_memo_SYNTHETIC.txt`: example internal memo (category internal_docs).

Run `python3 tools/intel_demo.py` to register sources, ingest these files and produce a report.
